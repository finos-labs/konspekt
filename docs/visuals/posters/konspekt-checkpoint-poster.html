konspekt · checkpoint and resume

Hand a conversation to another LLM, the next day, or another device

Type checkpoint and konspekt writes one row into the project graph in your git repository: the item the conversation is bound to, plus the pending proposals and open items, kept word for word. The next conversation reads it first and offers to continue there. You confirm.

Memory and project context built into LLM toolskonspekt checkpoint
Who writes itThe model, as a summaryYou issue it; the text is kept word for word
Where it livesWith the vendor, in one product and one accountIn your git repository, under version control
Who can read itThat productAny LLM or tool that can read the repository
What it recordsFacts and files, with no position in the workWhere the work stopped, checked against the graph on resume
