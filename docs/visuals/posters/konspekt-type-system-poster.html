The type system

Every atom in a konspekt graph is one of a small, closed set of types. This sheet gives the one question that selects each type, so the right one gets reached for and none goes unused.

Work nodes

GraphNode.type — what kind of work is this?
goal
An outcome you are driving toward, with a condition that says when it is reached.
feeds goal tree · child of decomposes
investigation
Open-ended inquiry. You do not yet know the answer, or what would settle it.
vs experiment: no stated expectation
experiment
A designed test with the expected result stated before you run it. The outcome confirms or refutes.
the discriminator: expectation up front
topic
A standing area of attention that never completes. Things attach to it over time.
vs goal: no completion condition
task
A concrete, bounded unit of work with a clear done state.
vs goal: bounded, not decomposed
note
A lightweight marker on the work tree. Not a Noteworthy atom, and not the NOTES.md scratchpad.
a node, not a finding
status   open · active · resolved · abandoned   —   a node can sit under more than one parent; hierarchy lives in edges

Noteworthy

Noteworthy.kind — what kind of finding is this? · arrives on a notes edge
fact
Established. Holds independent of who said it.
statement
Asserted by a source, not yet established.
decision
A choice made. See the decision rule below.
assumption
Taken as true, unvalidated. validate / refute moves it.
status unvalidated · validated · refuted
constraint
A limit that holds until lifted.
status active · lifted

Waypoints

the timeline axis — not part of the goal tree · arrives on marks
decision
An inflection choice worth seeing on the timeline.
milestone
A point reached.
pivot
A change of direction.

The decision rule

one decision, up to three representations — one rule for each
  • alwaysa Noteworthy (kind: decision) — the atomic, always-true record
  • + ifa Waypoint, when it is an inflection worth seeing on the timeline
  • + ifa Node, only when it opens a branch of work to track

Concept & Artifact

concept
An idea with a label, definition, and aliases for dedup. Referenced through mentions, never copied — so cross-linking is automatic and the project inventory is free.
referenced by mentions · associates via relates
artifact
A produced output: name, kind, location, version.
arrives on produces
