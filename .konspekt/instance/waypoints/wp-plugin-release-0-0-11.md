# Waypoint: konspekt IntelliJ plugin 0.0.11 released

The IntelliJ plugin was cut as release `intellij-plugin-v0.0.11`, the first build
that ships the **Resolve** write path alongside Accept in the tool window drawer.
The prebuilt zip (`konspekt-intellij-0.0.11.zip`) is attached to the GitHub
release and installs from disk into IntelliJ 2026.2 or newer; `/releases/latest`
now points at it. The 0.0.10 release predated the resolve work, so it carried
Accept only.
