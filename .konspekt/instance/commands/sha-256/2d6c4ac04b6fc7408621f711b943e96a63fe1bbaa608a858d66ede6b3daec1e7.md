konspekt IntelliJ plugin — the shared konspekt view (Changes / Stats / Goals / Decisions) in an IDE tool window, rendered in-process from the open project's `.konspekt/instance`.

## New in 0.0.18
- **External links open in the system browser.** An `http(s)` link in the view that points outside the plugin's view server (a store location, an origin locator) opens in the default system browser. Previously a `target="_blank"` link opened a bare Chromium window. Applies to the docked tool window and the pop-out window.

## Install (no build)
1. Download `konspekt-intellij-0.0.18.zip` from the assets below.
2. In **IntelliJ IDEA 2026.2 or newer**: Settings → Plugins → ⚙ → *Install Plugin from Disk…* → the downloaded zip, then restart when prompted.

Requires IntelliJ IDEA 2026.2 or newer (`since-build = 262`, no upper bound). The plugin is unsigned; install-from-disk does not require signing.

Under an instance that declares principals, set `KONSPEKT_PRINCIPAL` before starting the IDE, as in 0.0.12.

Building from source is optional and documented at `implementations/intellij-plugin/app/README.md`.
EOF
