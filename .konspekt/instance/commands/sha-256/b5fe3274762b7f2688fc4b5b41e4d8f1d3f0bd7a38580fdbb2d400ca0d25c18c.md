konspekt IntelliJ plugin — the shared konspekt view (Changes / Stats / Goals / Decisions) in an IDE tool window, rendered in-process from the open project's `.konspekt/instance`.

This release includes the 0.0.16 changes; 0.0.16 was not published separately.

## New in 0.0.17
- **Connections frame.** The atom drawer lists every edge that touches the entity, in both directions and across all edge kinds, grouped by kind. An edge whose review is `proposed` has a dashed border.
- **Navigate between entities.** Clicking a neighbor in the Connections frame, or an `[[id]]` link in the Details tab, opens that entity in the same drawer, with a back button and the path it was opened from. An `[[id]]` that names no entity stays plain text.
- **Pop-out graph.** "Pop out graph" opens the whole graph in an overlay with zoom, pan, a depth choice (1, 2, All), edge-kind filters, Find, and a side panel for the selected entity. The layout is a radial tree around the current entity. Nodes can be dragged; a moved position is kept until the layout is recomputed.
- **Read endpoints:** `GET /api/neighbors?id=` and `GET /api/fullgraph`.

## New in 0.0.16
- **Clickable references.** The Details tab links every `ni:///sha-256` reference, every `command:ni:` reference, and the SHA-1 values in `provenance.deprecated`. Clicking one opens the referenced content in the drawer, with its store location and a back button. A reference that does not resolve shows "no such content".
- **Provenance tab as a reference index**, in three groups: the extraction, the entity's transition-log rows, and its origin locators.
- **Read endpoints:** `/api/source` returns `location` expanded from `project.md` `store.resolve`; new `/api/command` and `/api/transitions`; `/api/entity` returns `provenance.deprecated` and the provenance metadata.

## Install (no build)
1. Download `konspekt-intellij-0.0.17.zip` from the assets below.
2. In **IntelliJ IDEA 2026.2 or newer**: Settings → Plugins → ⚙ → *Install Plugin from Disk…* → the downloaded zip, then restart when prompted.

Requires IntelliJ IDEA 2026.2 or newer (`since-build = 262`, no upper bound). The plugin is unsigned; install-from-disk does not require signing.

Under an instance that declares principals, set `KONSPEKT_PRINCIPAL` before starting the IDE, as in 0.0.12.

Building from source is optional and documented at `implementations/intellij-plugin/app/README.md`.
