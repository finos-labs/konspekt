**Claude (measurement):** `changed.md` binds 209 distinct commits; 130 have a row in `review-units.md`; the other 79 have none, and all 79 are on `origin/main`.

**Claude (proposal, `nw-direct-commits-recorded`):** an absent review-unit row is the only signal of a direct-to-main commit, but absence also means "on a branch whose pull request is not open yet" or "log not regenerated". Record direct commits explicitly: `tools/review-units.mjs` writes a row for each bound commit on the default branch that no review unit contains, with `state: direct`, empty review unit and merge commit, and the commit's timestamp. The spec adds `direct` to `state`; `review-unit-incomplete` allows an empty review unit only for `direct`. The UI shows "direct to main" only for `direct` rows and "no review unit yet" for a commit with no row. The checker may warn on a bound commit with no row.
