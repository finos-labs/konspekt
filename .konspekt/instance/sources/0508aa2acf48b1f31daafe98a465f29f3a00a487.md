Verbatim, 2026-09-20.

**Human:** I dont think clicking Accept does anything; the button shows, clicking does nothing. The dynamic sizing works, though

Diagnosis: the shared view's Accept used `window.confirm()`. In the IntelliJ JCEF
browser there is no JS-dialog handler, so `window.confirm()` / `alert()` /
`prompt()` silently return (confirm returns false), and the action aborted with no
visible effect. The same view worked in Electron and a plain browser. Fix: an
inline DOM confirm, no native dialogs, so one view behaves the same on every
surface.
