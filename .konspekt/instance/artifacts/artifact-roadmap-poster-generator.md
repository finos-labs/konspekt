# Artifact: Roadmap poster generator

Zero-dependency generator that emits `docs/visuals/posters/konspekt-roadmap-poster.html`
as a curated, graph-validated projection. It mirrors [[task-roadmap-generator]]'s
`tools/roadmap.mjs` (pure function of the instance, AUTOGENERATED banner with a
`contentHash`, `--check` freshness gate). A curated editorial map selects which
goals and tasks the poster shows; the generator binds that map to the graph —
each selected goal and task must exist and be reachable via `decomposes`, or
generation fails — so the poster cannot silently reference a task the graph no
longer has.
